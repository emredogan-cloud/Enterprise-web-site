# This folder is a signpost, not a document

It once held loose copies of the Phase 0 and Phase 1 reports and of the
Founder handbook, made outside the repository's layout. Three were byte-for-byte
duplicates of the canonical files; the fourth — `FOUNDER_ACTIONS.md` — was a
**stale Phase 1 snapshot** still asking for work that had since been done. A
second handbook that disagrees with the first is worse than no second handbook,
so the copies were removed on 2026-09-02 and replaced by this pointer.

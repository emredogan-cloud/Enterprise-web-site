# Every KDP book, audited again for a route back to Valice Press

**Read at:** 2026-09-03. Method: `pdftotext` and `pdfinfo` over the built interior of every print edition — what a KDP reviewer sees, not what the source claims — plus the companion registry and the catalogue. Re-runnable: `node scripts/factory/kdp-linkage-lint.mjs` (`--check-urls` asks production whether each printed address answers 200; `--strict` fails a book whose companion exists but is not printed, and is what Gate 10 runs). Per-edition data with every column the brief asked for: `KDP_VALICE_LINKAGE_MATRIX.csv`, regenerated by `kdp-linkage-matrix.mjs`.

Statuses are strict. **VERIFIED** = read from the built file. **BLOCKED** = named blocker, named owner.

## 2. What the second audit read that the first did not

The first pass checked URLs and the banned biography. This pass also reads, per edition:

- **PDF metadata.** The Field Book's interior carries `Title: untitled · Author: anonymous`. Every other interior carries its title and author. A library catalogue, a Kindle sideload and Amazon's own ingestion read that field.
- **Which biography is printed.** Three states, measured: *approved* (Codex Mythologica ×3, World Myths ×2, World Games ×2 — the Founder's own text), *non-canonical* (Codex Bestiarium ×3 — "writes reference books and retellings drawn from world folklore…", factual, no invented credential, but not the approved text), *absent* (Field Book, Hangul, Dudeney, Enigmatica — no biography printed at all), *invented* (World Games large print only).
- **Every URL on any host.** World Games cites `pagat.com`, `gambiter.com`, `goeastmandarin.com` (sources); the Field Book cites `Korea.net` and `plus.maths.org`; Hangul cites `korean.go.kr`. All are source citations, none is a store, none is a form.
- **References to Amazon.** After excluding "Amazons" and "Amazonia" (two books contain both), no interior references the retailer at all.
- **False listing claims.** No interior prints "120 Legendary Creatures"; the Bestiarium *listing* still does (handbook O4).
- **A QR code.** Detected by the sentence printed beside it ("Scan, or type the address"): World Myths ×2 carry one; World Games prints the URL only. A QR is vector art that pdftotext cannot see, so the sentence is the honest proxy and the matrix says so.

## 5. The gate

`compliance-lint.mjs` (Gate 10) now runs `kdp-linkage-lint` on the project's registered interiors: a non-canonical host, a data-wall URL, the invented biography, a broken PDF title/author, a false listing claim, or a companion that exists but is not printed is an **error**. `valice-house/workflows/gates.json` records it as Gate 10 evidence. Seven tests in `scripts/factory/kdp-linkage-lint.test.js` build real PDFs and read them back: COMPLETE, MISSING, the three refusals, BLOCKED, IN_REVIEW, and the registry read.

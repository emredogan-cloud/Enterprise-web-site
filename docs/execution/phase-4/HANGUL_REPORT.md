## A note on the SEO page

*Hangul stroke order: how to write all 40 letters, and where each order comes from* is live at `/blog/hangul-stroke-order`. It is built on the one thing this workbook has that no competing guide does: the recorded provenance of every stroke sequence — 28 transcribed from published diagrams, 12 derived from the rule, and the book says which is which. That distinction is the page's reason to exist and the book's reason to be trusted.

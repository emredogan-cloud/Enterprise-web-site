No prompt in this library was used. Nothing here was generated.

OPENAI_API_KEY is not present in this environment, verified at the start of the phase. No image model was available and none was called. Total image-generation spend for Phase 1: $0.00.

Every cover and every visual element shipped in Phase 1 was drawn by script — typographic covers in the Valice Classics identity, with the engraved device built from vector primitives (circles, rules, radial strokes) rather than raster art. That is the series identity described in valice-house/covers/COVER_STANDARDS.md, not a fallback: "emerald/black, Noto Serif Display, typographic + one fine engraved device (Meditations pattern)."

This library exists for two reasons. It records, honestly, that the phase generated no AI imagery — which is what the KDP AI declaration must say. And it holds the briefs that would be used if a key is added later, so that a future phase does not start from nothing.

Held briefs — for a future phase, if a key is added

These are written to the house cover standards. Each names the asset id, the book, the exact filename and destination, the dimensions, and the constraints. Rule 2 of the cover standards binds every one of them: all lettering is set in type, never rendered inside the image. An image model that renders text produces broken glyphs, and the Hangul workbook already shipped a defect of that kind once.

If a key is added later — the rules that still apply

  • Generated files go to generated/ and are never a slot file. Slots are front-v<n>.png, kindle-v<n>.jpg, paperback-wrap-v<n>.pdf and are composed by the build.
  • All lettering is set in type. Never ask a model for a title, an author name or a series line.
  • Title must be ≥25% of cover height and legible at 150 px. Check the thumbnail render, not the full-size one.
  • No QR code, URL or form on any cover — KDP disallows it. The companion address lives on the last leaf.
  • Record every generated asset in the cost ledger (node scripts/factory/cost-ledger.mjs) and update project_config.json → compliance.aiDisclosure.images from none to generated. The KDP declaration must follow.
  • Artwork resolution is recorded honestly. A cover that is 112 PPI at print size is written down as 112 PPI.

Phase 1 generated no images and spent nothing. This file is the record of that, and the starting point for a phase that does.
